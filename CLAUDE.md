Working conventions for Claude Code
- Read this SPEC.md at the start of each session.
- Keep timing logic out of the UI; keep the engine pure and tested.
- Don't change the tech stack, grading rules, or engine API without proposing the change and updating this spec first.
- When a decision isn't covered in the spec, pick the simplest option, note it in a "Decisions log" section at the bottom of the spec file, and continue.
